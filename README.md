# DentalFlow Agency Website

Sage green glass UI — AI booking for dental clinics in Dhaka.

## 🚀 Deploy to GitHub Pages (Free)

### Step 1 — Create a GitHub account
Go to [github.com](https://github.com) and sign up if you haven't already.

### Step 2 — Create a new repository
1. Click the **+** icon → **New repository**
2. Name it: `dentalflow-agency` (or anything you like)
3. Set it to **Public**
4. Click **Create repository**

### Step 3 — Upload the files
1. Click **uploading an existing file** on the repo page
2. Drag and drop ALL the files and folders from this project:
   - `index.html`
   - `assets/` folder (with `css/` and `js/` inside)
   - `README.md`
3. Click **Commit changes**

### Step 4 — Enable GitHub Pages
1. Go to your repo → **Settings**
2. Scroll to **Pages** in the left sidebar
3. Under **Source**, select **Deploy from a branch**
4. Choose branch: `main` → folder: `/ (root)`
5. Click **Save**

### Step 5 — Your site is live! 🎉
After ~60 seconds, your site will be at:
```
https://YOUR-USERNAME.github.io/dentalflow-agency/
```

| Facebook link | `index.html` → search `facebook.com/` |
| Clinic area (Uttara) | `index.html` → FAQ section |
| Agency name/tagline | `index.html` → hero section |
| Colours | `assets/css/style.css` → `:root` variables |
